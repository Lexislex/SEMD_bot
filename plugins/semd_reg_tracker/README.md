# SEMD Registration Tracker Plugin

## Описание

Плагин `semd_reg_tracker` - это ScheduledPlugin, который отслеживает регистрацию СЭМД в РЭМД и отправляет уведомления в `UPDS_MAILING_LIST` о начале и завершении регистрации СЭМД.

## Функциональность

### Основные возможности

- **Ежемесячная сводка** - информация о СЭМД, начинающих/завершающих регистрацию в текущем месяце
- **Ежеквартальная сводка** - информация о СЭМД за текущий квартал
- **Приоритет квартальной сводки** - если 1 число совпадает с началом квартала, отправляется только квартальная сводка
- **Группировка по датам** - сообщения структурированы по датам начала/окончания регистрации

### Расписание работы

#### Production режим
- **1 число каждого месяца в 10:00 MSK** - месячная сводка (если не начало квартала)
- **1 число каждого квартала в 10:00 MSK** - квартальная сводка (1.01, 1.04, 1.07, 1.10)

#### Development режим
- **Каждую минуту** - месячная проверка
- **Каждые 3 минуты** - квартальная проверка

## Компоненты

### plugin.py - Plugin класс

Основной класс плагина, наследует `BasePlugin`:

- `get_name()` - возвращает "SEMDRegTracker"
- `get_version()` - возвращает версию плагина
- `initialize()` - инициализация плагина
- `get_scheduled_tasks()` - возвращает две задачи (месячная + квартальная)
- `check_monthly_updates()` - проверка и отправка месячной сводки
- `check_quarterly_updates()` - проверка и отправка квартальной сводки

### handlers.py - SEMDRegistrationHandlers

Обработчик логики:

**Методы фильтрации:**
- `_get_monthly_registrations(year, month)` - СЭМД, начинающие регистрацию в месяц
- `_get_monthly_terminations(year, month)` - СЭМД, завершающие регистрацию в месяц
- `_get_quarterly_registrations(year, quarter)` - СЭМД за квартал (начало)
- `_get_quarterly_terminations(year, quarter)` - СЭМД за квартал (конец)

**Методы группировки:**
- `_group_by_date(df, column='START_DATE')` - группирует по датам, возвращает список `DateGroup`

**Методы отправки:**
- `send_monthly_update()` - отправляет месячную сводку в рассылку
- `send_quarterly_update()` - отправляет квартальную сводку в рассылку

**Структура DateGroup:**
```python
DateGroup(
    date=datetime.date(2025, 1, 1),
    semds=[
        ('119', 'Протокол консультации (CDA) Редакция 4'),
        ('134', 'Предоперационный эпикриз (CDA) Редакция 1'),
    ]
)
```

### formatters.py - SEMDRegistrationFormatter

Форматирует сообщения для отправки:

- `format_monthly(registrations, terminations, year, month)` - месячная сводка
- `format_quarterly(registrations, terminations, year, quarter)` - квартальная сводка
- `_format_date_group(date_group)` - форматирует группу СЭМД по одной дате
- `should_send_silent()` - возвращает False (отправляем со звуком)

## Данные

Плагин использует справочник SEMD1520 (OID: `1.2.643.5.1.13.13.11.1520`):

**Используемые колонки:**
- `OID` - идентификатор СЭМД
- `NAME` - наименование СЭМД
- `START_DATE` - дата начала регистрации
- `END_DATE` - дата окончания регистрации
- `FORMAT` - формат документа
- `TYPE` - тип документа

## Интеграция с core/scheduler.py

Плагин использует расширенный `TaskScheduler`:

**Новые возможности:**
- Параметр `at` для указания времени выполнения ("HH:MM")
- Поддержка `unit='months'` и `unit='quarters'`
- Методы-помощники:
  - `is_first_of_month()` - проверка первого числа месяца
  - `is_first_of_quarter()` - проверка первого числа квартала
  - `get_current_quarter()` - получение текущего квартала

## Обработка ошибок

- Graceful degradation при невозможности загрузить справочник
- Логирование всех ошибок
- Try-catch для всех критических операций
- Отправка в каждый chat_id отдельно с обработкой ошибок

## Пример использования

