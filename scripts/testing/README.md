# Testing Scripts

Скрипты для тестирования архитектуры и функциональности SEMD Bot.

## 🧪 Тесты

### test_architecture.py — Тест архитектуры

Проверяет что вся архитектура работает правильно без реального запуска бота.

**Что проверяет:**
- ✅ Создание SEMDBotCore
- ✅ Загрузка плагинов
- ✅ Инициализация планировщика
- ✅ Конфигурация

**Запуск:**
```bash
uv run python scripts/testing/test_architecture.py
```

**Ожидаемый результат:**
```
🧪 ТЕСТ АРХИТЕКТУРЫ SEMD Bot v2.0
✅ ВСЕ ТЕСТЫ ПРОЙДЕНЫ УСПЕШНО!
```

## 🔄 Типичный workflow

```bash
# 1. Очистить базы данных
uv run python scripts/database/clean_all_db.py --backup

# 2. Запустить архитектурный тест
uv run python scripts/testing/test_architecture.py

# 3. Если тесты пройдены, запустить бота
uv run python main.py
```

## 💡 Советы

- Всегда запускайте тесты перед отправкой кода в репозиторий
- Если тесты падают, проверьте логи в выводе
- Убедитесь что БД очищены перед тестированием
