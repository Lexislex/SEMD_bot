# Руководство по очистке баз данных

Проект содержит два скрипта для удобной очистки баз данных в процессе разработки и тестирования.

## 📊 Информация о базах

- **fnsi_data.sqlite** — данные о справочниках ФНСИ (таблица `nsi_passport`)
- **user_data.sqlite** — данные пользователей и их активность (таблицы `users`, `users_activity`)

Обе базы находятся в директории `env/data/`

---

## 🧹 Скрипт 1: Очистка FNSI базы (`clean_fnsi_db.py`)

Гибкий скрипт для работы с базой справочников ФНСИ.

### Показать информацию о базе

```bash
uv run python clean_fnsi_db.py --info
```

Выведет:
- Путь к базе
- Размер в MB
- Список таблиц и количество записей в каждой

### Удалить только данные (сохранить схему)

```bash
uv run python clean_fnsi_db.py --keep-schema
```

Полезно когда нужно сохранить структуру таблиц, но очистить все записи.

### Полная очистка (удалить базу)

```bash
uv run python clean_fnsi_db.py
```

Удалит всю базу. При следующем запуске бота она будет пересоздана с нулевой структурой.

### Полная очистка с резервной копией

```bash
uv run python clean_fnsi_db.py --backup
```

Перед удалением создаст резервную копию с временной меткой:
- `fnsi_data_backup_20251101_145000.sqlite`

### Пользовательский путь к базе

```bash
uv run python clean_fnsi_db.py --info --db-path /path/to/custom/db.sqlite
```

## 🗑️ Скрипт 2: Быстрая очистка FNSI (`clean_fnsi_db_quick.sh`)

Самый быстрый способ удалить FNSI базу **без подтверждения**.

```bash
./clean_fnsi_db_quick.sh
```

или

```bash
bash clean_fnsi_db_quick.sh
```

✅ Идеально для CI/CD и автоматизации тестирования.

---

## 🧹🧹 Скрипт 3: Очистка всех баз (`clean_all_db.py`)

Удаляет **обе базы данных** (FNSI и User) одновременно.

### Показать информацию о всех базах

```bash
uv run python clean_all_db.py --info
```

Выведет подробную информацию о размере, таблицах и записях в каждой базе.

### Полная очистка всех баз

```bash
uv run python clean_all_db.py
```

Требует подтверждения перед удалением.

### Очистка с резервными копиями

```bash
uv run python clean_all_db.py --backup
```

Создаст резервные копии для обеих баз:
- `fnsi_data_backup_20251101_145000.sqlite`
- `user_data_backup_20251101_145000.sqlite`

## 📋 Рекомендуемые сценарии использования

### 🔍 Отладка проблем с обновлением справочников

```bash
# 1. Посмотреть текущее состояние
uv run python clean_fnsi_db.py --info

# 2. Очистить только FNSI базу
uv run python clean_fnsi_db.py

# 3. Запустить бота для тестирования
uv run python main.py
```

### 🧪 Полное тестирование с чистыми данными

```bash
# 1. Создать резервные копии на случай
uv run python clean_all_db.py --backup

# 2. Удалить все базы
uv run python clean_all_db.py

# 3. Запустить тестовый скрипт
uv run python test_architecture.py

# 4. Запустить бота
uv run python main.py
```

### 🚀 Быстрая подготовка к демонстрации

```bash
# Быстро очистить FNSI без вопросов
./clean_fnsi_db_quick.sh

# Запустить бота
uv run python main.py
```

### 📦 Подготовка проекта перед коммитом

```bash
# Очистить обе базы с резервными копиями
uv run python clean_all_db.py --backup

# Проверить что всё в порядке
uv run python test_architecture.py
```

## ⚠️ Важные замечания

### Резервные копии

- Резервные копии создаются только если вы указали флаг `--backup`
- Они сохраняются в `env/data/` с временной меткой
- Размеры обычно в диапазоне **0.05-0.10 MB**

### Подтверждение операций

- Скрипты `clean_fnsi_db.py` и `clean_all_db.py` требуют подтверждение (введите `да`)
- `clean_fnsi_db_quick.sh` удаляет без подтверждения
- Всегда показывают информацию ДО удаления

### Восстановление данных

Если вы случайно удалили базу без резервной копии:

1. **FNSI база** пересоздается автоматически при запуске бота
2. **User база** пересоздается автоматически при регистрации первого пользователя
3. Вся история потеряна (используйте `--backup` в будущем!)

## 🔧 Troubleshooting

### Ошибка: "База данных заблокирована"

```
Error: database is locked
```

**Решение:** Остановите бота и убедитесь, что нет других процессов обращающихся к БД:

```bash
# Завершить все процессы Python
pkill -f "python.*main.py"
```

### Ошибка: "Нет прав доступа"

```
PermissionError: [Errno 13] Permission denied
```

**Решение:** Проверьте права доступа на папку:

```bash
chmod 755 env/data/
chmod 644 env/data/*.sqlite
```

### База не удаляется

**Решение:** Используйте флаг `--backup` чтобы видеть, что происходит:

```bash
uv run python clean_all_db.py --backup --info
```

## 💡 Про Git и базы данных

В `.gitignore` уже исключены файлы БД:

```gitignore
env/data/*.sqlite
env/data/*_backup_*.sqlite
```

Поэтому ваши локальные БД никогда не будут добавлены в репозиторий. 🎉
